Screen Matcher 사용법

[실행]
1. ScreenMatcher.exe 를 실행한다. 관리자 권한 확인창이 뜨면 '예'.
   - Windows Defender 경고가 뜨면 '추가 정보' → '실행'.
2. '스마트 앱 컨트롤'이 막아서 실행이 안 되면:
   - python.org 에서 Python 3.10 이상을 설치한다. 설치 화면에서 "Add python.exe to PATH" 를 꼭 체크.
   - run.bat 을 더블클릭한다. 처음 한 번만 1~2분 동안 패키지를 설치한다.
   - 대상 프로그램이 관리자 권한이면 run.bat 을 우클릭 → '관리자 권한으로 실행'.

[설정 - 화면의 ①~④ 카드 순서대로]
1. ① 대상 창: 목록에서 프로그램 창을 고른다. 없으면 '창 목록 새로고침'. 입력·캡처는 '자동' 그대로.
2. ② 찾을 이미지: '화면에서 드래그로 등록' → 찾을 그림을 드래그로 감싸고 이름·점수·최소 개수를 넣는다.
3. '현재 화면 분석'으로 몇 개 잡히는지 확인한다. 엉뚱한 곳이 잡히면 임계값을 올리고, 못 찾으면 내린다.
4. ③ 반복 동작: '화면에서 클릭으로 지정' → 뜨는 화면에서 반복해서 누를 버튼을 클릭.
   버튼을 누른 뒤 확인창이 뜨는 프로그램이면 후속 동작을 Enter 키 / 위치 클릭으로 정한다.
5. ③ 종료 조건: 점수 합 / 분류 개수 / 이미지별 최소 개수 중 쓸 것을 켠다.
6. '1회 클릭 테스트'로 입력이 들어가는지 확인한다. 화면이 안 바뀌면 입력을 '포그라운드'로 바꾼다.

[실행하기]
1. ④ '▶ 시작' → 3초 뒤 반복한다. F9 또는 '■ 정지'로 멈춤.
2. 조건을 만족하면 소리가 나고 멈춘다. captures 폴더에 그때 화면이 저장된다.

[입력 방식]
- 입력 '자동'(기본)은 대상 창에 직접 메시지를 보내서 커서·포커스를 바꾸지 않는다. 실행 중에도 다른 작업을 할 수 있다.
- 대상이 반응하지 않으면 실제 입력(포그라운드)으로 바뀐다. 이때는 마우스가 멈출 때까지 기다렸다가 클릭하고,
  커서 위치와 원래 창 포커스를 되돌린다. (입력 잠금은 관리자 권한일 때만 됨)

[주의]
- 다른 프로그램에 입력을 보내는 도구다. 자동 입력을 허용하지 않는 서비스(온라인 게임, 예매·구매 사이트 등)에는 쓰지 않는다.
